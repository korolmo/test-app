# Редактор полигонов

Одностраничное веб-приложение для создания и редактирования полигонов на `canvas`.  
Проект выполнен на чистом JavaScript с использованием `Web Components` и собирается через `webpack`.

## Основные возможности

- генерация случайных полигонов;
- выбор полигона кликом;
- перетаскивание с ограничением по границам холста;
- запрет наложения полигонов;
- удаление выбранного полигона;
- удаление всех полигонов;
- `Undo / Redo` для генерации, удаления, изменения цвета и перемещения;
- изменение цвета выбранного полигона;
- экспорт сцены в `JSON`;
- импорт сцены из `JSON`.

## Требования

- `Node.js` 20+;
- `npm`.

## Установка зависимостей

```bash
npm install
```

## Запуск проекта

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8080
```

## Сборка

```bash
npm run build
```

Результат сборки будет создан в папке `dist/`.

## Горячие клавиши

- `Delete` — удалить выбранный полигон;
- `Ctrl+Z` / `Cmd+Z` — отменить действие;
- `Ctrl+Y` или `Ctrl+Shift+Z` / `Cmd+Shift+Z` — повторить действие.

## Структура проекта

```text
src/
  components/   Web Components и пользовательский интерфейс
  core/         состояние, история, генерация, import/export сцены
  utils/        геометрические вычисления
```
